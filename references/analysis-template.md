# Findings template — Claim / Evidence / Regulatory basis

## Schema
| # | Finding (claim) | Severity | Evidence (extract) | MU 20/15 / FAA-N16 clause | Breach summary | Action |
|---|---|---|---|---|---|---|
|   |   | MVI / V / LVI | "exact extract or page ref" | §x.y | what was breached | flag for complaint / keep |

## Severity key
- MVI = material (relied on in a complaint)
- V = high (strong supporting evidence)
- LVI = low (supplementary)
